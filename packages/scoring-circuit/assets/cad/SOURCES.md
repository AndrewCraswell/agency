# CAD model sources

These checked-in STEP files are the source copies used to select the board's rendered component models. Manufacturer
models distributed only in archives and the color-corrected Kingbright render variants are loaded from these checked-in
copies. Other models use pinned upstream URLs so the tscircuit STEP converter can load them during a build.

Kingbright publishes one WP7113 package model for all three selected colors and states that its rendered lens color is
for display only. The red and white files change only the two STEP presentation-color records so the board preview is
legible; their mechanical geometry is byte-for-byte the official model. The BOM identities `WP7113ID`, `WP7113GD`, and
`WP7113QWC/D` define the physical parts.

The complete ESP32-S3-DevKitC-1-N8R2 carrier has a public CC BY 4.0 model on
[Flux](https://www.flux.ai/samanthadiaz08/esp32-s3-devkitc-1-tra8?editor=code). N8R2 and N8R8 use the same DevKitC
carrier and WROOM-1 mechanical envelope, but Flux requires an account to export the STEP asset. Until an unrestricted
download is available, the preview renders Espressif's exact WROOM-1 module plus the exact 1x22 socket rows and retains
the carrier outline in PCB silkscreen. It does not substitute a fabricated box for the missing carrier model.
