## Manufacturer package and land guidance

The exact-part detail and catalog identify the package as CGA3, metric 1608
and EIA 0603. The manufacturer package dimensions are length 1.60 mm with
`+0.20/-0.10 mm`, width 0.80 mm with `+0.20/-0.10 mm`, and thickness 0.80 mm
with `+0.20/-0.10 mm`. The retained minimum terminal width is 0.20 mm and
minimum terminal spacing is 0.30 mm.

For reflow, the exact-part report gives PA = 0.60 to 0.80 mm, PB = 0.60 to
0.80 mm, and PC = 0.60 to 0.80 mm. The associated manufacturer image shows PA
as the copper gap between pads, PB as pad length along the capacitor long
axis, and PC as pad width across the package. Flow guidance is retained in
code as PA = 0.70 to 1.00 mm, PB = 0.80 to 1.00 mm, and PC = 0.60 to 0.80 mm;
this candidate selects reflow only.

## Project derivation

The project review selection uses the midpoint of each reflow range: PA = 0.70
mm, PB = 0.70 mm, and PC = 0.70 mm. Therefore:

- copper pad length = PB = 0.70 mm;
- copper pad width = PC = 0.70 mm;
- copper gap = PA = 0.70 mm;
- overall land span = PA + 2 x PB = 2.10 mm;
- pad centers = plus or minus `(PA + PB) / 2` = plus or minus 0.70 mm.

The project mask opening is 0.80 mm x 0.80 mm from a 0.05 mm per-edge
expansion. The project paste opening is 0.60 mm x 0.60 mm from a 0.05 mm
per-edge reduction. The review courtyard is 2.40 mm x 1.30 mm with 0.15 mm
minimum clearance, derived from the larger of the selected land span and
package envelope in each axis. These are project inputs, not TDK CAD.

The rendered tscircuit review geometry includes two 0.70 mm x 0.70 mm copper
