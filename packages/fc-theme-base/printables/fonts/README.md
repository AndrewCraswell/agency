# Print Fonts

Static instances of the Fencing Club typefaces used in the printable tape PDFs:

- Archivo SemiBold: Google Fonts `ofl/archivo/Archivo[wdth,wght].ttf`, weight 600, width 100.
- Inter Regular and SemiBold: Google Fonts `ofl/inter/Inter[opsz,wght].ttf`, optical size 14, weights 400 and 600.

Downloaded from the Google Fonts repository and instantiated with the installed fontTools package. The adjacent OFL
files contain the upstream font licenses. Fonts are embedded and subset when generating the PDFs; rebuilding does not
require a network connection or fontTools.
